AI Prompt Optimizer Toolkit
An open-source, lightweight Python utility designed to assist creators and developers in structuring, refining, and scaling raw prompt ideas into highly effective prompts for state-of-the-art AI generation models.

Features
Dynamic Style Injector: Automatically applies tailored style modifiers (Chibi, Cinematic, Cyberpunk, etc.).

Structured JSON Output: Returns clean, modular JSON payloads ideal for pipeline integration.

Aspect Ratio Automation: Standardizes generation parameters seamlessly.

Installation
git clone https://github.com/luciabentancur03-eng/ai-prompt-optimizer-toolkit.git

Quick Start
python optimizer.py
